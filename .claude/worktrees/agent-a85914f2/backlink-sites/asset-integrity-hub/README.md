# Asset Integrity Digital Hub

A comprehensive Next.js 14 satellite site focused on digital transformation in asset integrity management, specifically targeting NDT, inspection, and asset management audiences.

## Purpose

This is Site #3 in a backlink strategy for atlantisndt.com, focusing on:
- Digital twins for asset management
- ERP solutions for inspection companies
- NDT software landscape
- Intelligent reporting
- Professional talent networks (NDTConnect)

All content includes strategic backlinks to key atlantisndt.com product pages.

## Technology Stack

- **Framework**: Next.js 14
- **React**: 18.2.0
- **Styling**: Tailwind CSS 3.4.1
- **Language**: TypeScript
- **Build Output**: Standalone
