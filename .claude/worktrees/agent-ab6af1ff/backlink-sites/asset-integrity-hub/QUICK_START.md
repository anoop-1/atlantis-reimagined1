## 🚀 Getting Started (5 minutes)

### 1. Navigate to the Project
```bash
cd /sessions/modest-cool-bohr/mnt/atlantis-reimagined1/backlink-sites/asset-integrity-hub
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the site.

## 💡 Tips

### Edit Content
All page content is in TypeScript files in `src/app/`. Edit the JSX to change content.

### Update Styles
Global styles in `src/app/globals.css` and `tailwind.config.ts`. Use Tailwind classes in JSX.

### Add Pages
Create new folders with `page.tsx` in `src/app/` to add more pages.

### Change Colors
Update color values in `tailwind.config.ts` under `colors.primary` and `colors.secondary`.
