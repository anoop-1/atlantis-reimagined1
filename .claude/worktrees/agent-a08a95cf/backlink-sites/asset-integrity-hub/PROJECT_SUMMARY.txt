   cd /sessions/modest-cool-bohr/mnt/atlantis-reimagined1/backlink-sites/asset-integrity-hub
   npm install
   npm run dev
   → Opens at http://localhost:3000

2. TESTING
   - Click through all pages to verify functionality
   - Check all links work correctly
   - Test mobile responsiveness
   - Verify metadata in page source

3. BUILD FOR PRODUCTION
   npm run build
   npm start
   → Production version runs at http://localhost:3000

4. DEPLOYMENT
   - Vercel: `vercel deploy` (automatic from git)
   - Netlify: Connect GitHub repository
   - AWS: Push to AWS S3 + CloudFront
   - Other: Node.js server with `npm start`
