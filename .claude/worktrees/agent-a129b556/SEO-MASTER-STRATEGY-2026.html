3. Technical SEO Audit — Critical Issues

3.1 Indexing Crisis — 0 Sitemap-Indexed Pages

PROBLEM: GSC reports 366 submitted URLs, 0 indexed via sitemap. Google is indexing pages through organic discovery but completely ignoring the sitemap. This is a known issue with SPAs that use catch-all rewrites.

Root Causes:

  1. SPA Rewrite Rule: "/(.*)" → "/" in vercel.json means all URLs return the same HTML shell. Google may see this as duplicate content.
  2. Client-Side Rendering: React hydrates content client-side. Googlebot may not execute JS for all 366 pages during crawl budget.
  3. Prerender Script: The build uses scripts/prerender.mjs but we need to verify it generates unique static HTML for EVERY route.
  4. Duplicate Sitemap: Both sitemap.xml and sitemap_index.xml are submitted — this confuses Google.

Fixes Required:

  • Verify prerender output: every URL in sitemap must have unique static HTML in /dist
  • Remove duplicate sitemap_index.xml submission — keep only sitemap.xml
  • Add lastmod dates to sitemap entries (Google prioritizes fresh content)
  • Implement ISR (Incremental Static Regeneration) or full SSG for all pages
  • Add <link rel="canonical"> as static HTML in prerendered output (not just React-injected)
  • Force re-crawl via GSC Indexing API for all 366 URLs after fixes
