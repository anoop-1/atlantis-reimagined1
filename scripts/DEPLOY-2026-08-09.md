# Deploy + index runbook — 2026-08-09 cycle

Everything below is **already written to disk and verified**. The only steps that
could not be run from the analysis sandbox are the ones needing `git` writes and
a platform build:

* `git` cannot rewrite its index on the mounted filesystem (`unlink: Operation
  not permitted`), so nothing is staged or committed.
* `vite build` cannot run there either — `node_modules` holds **Windows** esbuild
  binaries and the sandbox is Linux. `node_modules` was deliberately left
  untouched rather than reinstalled, so your local setup is unchanged.

Both run normally from your own machine.

## 2. Verify the deploy is actually live before claiming anything

```powershell
# confirm the deployed SHA matches HEAD (§23.4 — do not skip)
git rev-parse HEAD
npx vercel inspect atlantisndt.com

# the five new routes should return 200 with real prerendered HTML
foreach ($u in @(
  "https://atlantisndt.com/ndt-level-1-salary",
  "https://atlantisndt.com/ndt-level-2-salary",
  "https://atlantisndt.com/ndt-level-3-salary",
  "https://atlantisndt.com/ndt-inspector-salary",

  $r = Invoke-WebRequest $u
  "{0}  {1}  {2} bytes" -f $r.StatusCode, $u, $r.Content.Length

```

CLAUDE.md record that empty-shell regressions are a recurring class here.

## 4. Submit for indexing

```powershell
# Google Indexing API — 10 service accounts x 200/day = 2,000/day cap.
# NOTE the flag is --source, and it takes a LINE-DELIMITED file (not the JSON).
node scripts/gsc-multi-account-submit.mjs --source indexing-queue-2026-08-09.txt

# instant, uncapped — Bing/Yandex/Seznam
node scripts/indexnow-ping.mjs
```

The queue is already built and **dry-run verified against all 10 service
accounts** (all authenticated successfully):

```
Queue: 72 total URLs
  Unique content:       48
  Curated cities (60):  19
  Excluded (noindex):    5   <- ERP city pages; they become indexable after this deploy
  Submitting:           67
  Already in ledger:    44   <- skipped by the deduper
  Net new:              23
```

Two things worth knowing before you read the output:

* **The 5 "excluded (noindex)" URLs are ERP city pages that this deploy makes
  indexable.** Run the submit step *after* the deploy, not before, or they will
  be skipped again for a condition that no longer applies.
* **44 URLs are skipped as already-submitted.** That deduper is designed for
  *new* URLs and does not know that these pages' content changed. For the
  pricing-fixed pages the goal is a re-crawl to refresh the SERP snippet, which
  Google schedules on its own regardless of submission — so this is a real
  limitation, not something to work around by clearing the ledger. The titles
  and meta descriptions will update on the next natural crawl.

Total capacity used: 67 of 2,000/day. There is no need to batch this.

## 5. What is in the indexing list, and the honest expectation

| Group | URLs | Why |
|---|---:|---|
| New pages | 5 | Never crawled; need discovery |
| Pricing-fixed, SERP-visible | 13 | Titles/meta changed — Google must re-crawl to update the snippet it shows |
| Corporate-training verticals | 15 | Rendered price table removed |
| ERP city texture | 11 | Substantial new content + indexability change |
| Schema-corrected | 12 | Offer blocks changed |
| Corrupt-text repairs | ~20 | Live prose fixed on money pages |

**Indexing submission does not produce rankings.** It shortens discovery, which
is worth the most on the five genuinely new URLs and near-zero on pages Google
already crawls daily. The measurable outcomes from this cycle arrive on Google's
own re-crawl and ranking-establishment schedule — this repo's own record puts
that at 2-4 weeks for re-crawl and longer for ranking (§6a of the 2026-08-07
audit). Re-measure on the checkpoint below rather than tomorrow.

## 7. Two things this cycle deliberately did NOT do

1. **No bulk ERP/DT city permutations.** Measured this cycle: blog pages earn
   **295 impressions each**, ERP city pages earn **6**. 1,294 ERP-family pages
   produce 2.2% of site impressions. Adding more is the lowest-value action
   available, and §20.2 already says so.
2. **No unblocking of the 49 research-free ERP pages.** They earn 59 impressions
   between them in 90 days. Varying boilerplate to slip them past the duplicate
   gate would manufacture doorway pages for no traffic.
