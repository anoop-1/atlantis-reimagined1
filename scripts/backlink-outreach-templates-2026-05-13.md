## Template 4 — Industry forum, answer template

Use only when answering a specific question on NDT.net forum, Inspectioneering Forum, Eng-Tips, or Reddit. Do not post unsolicited promotional content. Do not link unless the link materially answers the question.

Pattern:

1. Address the specific question first. Be technically correct. Cite the standard clause if relevant (e.g., SNT-TC-1A 8.2, ISO 9712 7.4, API 510 6.5).

2. Share the answer in plain language with one concrete example from real shop practice.

3. Link only when a free resource directly answers the question. If you link, add the disclosure line.

4. Disclosure line, exact wording:
   "Full disclosure: I run Atlantis NDT (an ERP for NDT shops). The linked resource is free and does not require signup."

5. Do not link to the homepage or pricing page from a forum answer. Link only to the specific free template, calculator, or article that answers the question.

6. If the question does not need a link, do not include one. Answer the question and stop.

Sample answer skeleton:

"Per [STANDARD CLAUSE], the requirement is [X]. In practice most shops handle this by [Y]. The most common failure mode is [Z] — auditors catch this when [W].

If it helps, here is the specific [TEMPLATE / CALCULATOR] I use for this: [SINGLE LINK].

Full disclosure: I run Atlantis NDT (an ERP for NDT shops). The linked resource is free and does not require signup."
