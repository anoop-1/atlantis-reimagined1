HOW TO DEPLOY YOUR 20 SATELLITE BACKLINK SITES TO VERCEL
================================================================================

STEP-BY-STEP DEPLOYMENT GUIDE

================================================================================
STEP 1: OBTAIN YOUR VERCEL TOKEN
================================================================================

1. Visit https://vercel.com/account/tokens
2. Log in with your Vercel account
3. Click "Create Token"
4. Fill in details:
   - Token Name: "Satellite Sites Deployment" (or any name you prefer)
   - Scope: Select all scopes (default is fine)
5. Click "Create Token"
6. Copy the generated token (it will only be shown once)
7. Keep this token safe and secure

================================================================================
STEP 2: DEPLOY ALL SITES USING THE SCRIPT
================================================================================

Option A: Using the Automated Script (RECOMMENDED)

1. Open a terminal/command prompt
2. Navigate to the scripts directory:
   cd /sessions/admiring-relaxed-turing/mnt/atlantis-reimagined1/scripts

3. Run the deployment script with your token:
   VERCEL_TOKEN=your-token-here ./deploy-satellites.sh

   Example:
   VERCEL_TOKEN=abcd1234efgh5678ijkl9012 ./deploy-satellites.sh

4. Wait for the script to complete (5-15 minutes)
5. Review the output for success/failure status

Option B: Manual Deployment (If script doesn't work)

For each site, run:
   cd /sessions/admiring-relaxed-turing/mnt/atlantis-reimagined1/backlink-sites/{site-name}
   /sessions/admiring-relaxed-turing/node_modules/.bin/vercel deploy --prod --yes --token=your-token-here

Example:
   cd /sessions/admiring-relaxed-turing/mnt/atlantis-reimagined1/backlink-sites/pipeline-integrity-guide
   /sessions/admiring-relaxed-turing/node_modules/.bin/vercel deploy --prod --yes --token=abcd1234efgh5678ijkl9012

================================================================================
WHAT HAPPENS DURING DEPLOYMENT
================================================================================

For each of the 20 sites, the script will:

1. Navigate to the site directory
2. Create vercel.json if it doesn't exist (with Next.js configuration)
3. Execute: vercel deploy --prod --yes --token=$VERCEL_TOKEN
4. Vercel will:
   - Build the Next.js application
   - Upload files to Vercel's servers
   - Assign a unique deployment URL
   - Set up automatic HTTPS/SSL
   - Deploy to Vercel's global CDN
5. Script captures the deployment URL
6. Script logs success/failure

Expected Deployment Time per Site:
- Build time: 30-120 seconds (depends on dependencies)
- Upload time: 5-10 seconds
- Total per site: ~1-2 minutes
- All 20 sites: 20-40 minutes total

================================================================================
TROUBLESHOOTING
================================================================================

Problem: "VERCEL_TOKEN environment variable is not set"
Solution:
  Make sure you're using the exact command format:
  VERCEL_TOKEN=your-token-here ./deploy-satellites.sh
  
  Replace "your-token-here" with your actual token

Problem: "not authenticated" or "401 Unauthorized"
Solution:
  Your token is invalid or expired
  Steps:
    1. Get a new token from https://vercel.com/account/tokens
    2. Delete the old token (optional)
    3. Run deployment script again with new token

Problem: "Build failed"
Solution:
  The build process encountered an error
  Check the error message for details
  Common causes:
    - Missing dependencies (npm install first)
    - TypeScript compilation errors
    - Configuration issues in next.config.js
  
  To debug:
    1. cd to the site directory
    2. Run: npm install && npm run build
    3. Fix any errors
    4. Retry deployment

Problem: "Network error" or "Connection timeout"
Solution:
  Temporary connection issue
  Wait a few moments and retry
  Check your internet connection
  Check Vercel status: https://www.vercel-status.com/

Problem: Script doesn't exist or can't execute
Solution:
  Make sure you're in the correct directory:
    cd /sessions/admiring-relaxed-turing/mnt/atlantis-reimagined1/scripts
  
  Make sure the script is executable:
    chmod +x deploy-satellites.sh
  
  Run with explicit bash:
    bash deploy-satellites.sh

Problem: Only some sites deployed successfully
Solution:
  Check the summary report:
    cat /sessions/admiring-relaxed-turing/mnt/atlantis-reimagined1/backlink-sites/DEPLOYMENT_SUMMARY.txt
  
  For failed sites, retry individually:
    cd /sessions/admiring-relaxed-turing/mnt/atlantis-reimagined1/backlink-sites/{failed-site}
    /sessions/admiring-relaxed-turing/node_modules/.bin/vercel deploy --prod --yes --token=your-token
